LES PETITES QUESTIONS

Avant de pousser
la porte.

Un vrai bureau doit aussi être simple à comprendre. Voici ce qu’il faut savoir avant de commencer.

Est-ce une application locale ou un service en ligne ?+

L’interface et les fichiers du bureau sont sur votre ordinateur. Elle s’ouvre dans votre navigateur à l’adresse http://localhost:4850.

Les missions utilisent les clients officiels Codex ou Claude Code : les contenus nécessaires au travail sont transmis au fournisseur choisi. Ce n’est donc pas un modèle IA qui fonctionne entièrement hors ligne.

Quel abonnement faut-il ?+

Un abonnement et un compte donnant accès au client officiel choisi : ChatGPT via Codex, ou Claude via Claude Code. La connexion se fait dans le navigateur officiel, sans clé API à saisir.

Les quotas, l’accès aux modèles et les conditions du fournisseur continuent de s’appliquer. L’application n’ajoute pas de crédits ni d’accès à votre abonnement. Une démo sans appel IA permet de découvrir le bureau.

Puis-je installer Oscar sur un SSD externe ?+

Oui. Branchez le SSD puis lancez la commande d’installation : le Terminal propose les disques montés par leur nom. Choisissez son numéro et confirmez les dossiers du logiciel et des données. Vous n’avez pas à écrire son chemin à la main.

Pour des chemins précis ou une installation automatisée, les options avancées ci-dessus préparent une commande avec --dir et --data-dir. Un disque absent ne déclenche pas d’installation de remplacement sur le disque interne. Le changement d’emplacement ne déplace pas automatiquement les anciennes missions.

Où retrouver mes missions et mes documents ?+

Dans le dossier de données confirmé pendant l’installation. Sur le disque interne, le choix habituel est Documents/Oscar et les agents ; sur un SSD, le récapitulatif indique son dossier Oscar et les agents/Donnees. Chaque mission possède un dossier avec une date et un titre lisible, puis ses fichiers de travail et sa livraison.

Le bureau propose aussi un lecteur de fichiers et un accès au dossier local. Jusqu’à quatre missions peuvent avancer en parallèle. Elles partagent une capacité de vingt spécialistes au travail, avec vingt agents par mission et quatre par métier au maximum. Les contributions indépendantes démarrent depuis un brief commun ; l’intégration et les vérifications attendent leurs résultats réels.

Une équipe plus nombreuse utilise davantage votre abonnement sans garantir une accélération proportionnelle. Les quotas de votre moteur continuent de s’appliquer.

Les voix et le microphone sont-ils obligatoires ?+

Non. Le clavier et les sous-titres fonctionnent sans installer de moteur vocal. Oscar et Zoé peuvent parler avec des voix locales facultatives, à télécharger seulement après votre confirmation.

La dictée locale est également facultative. Le micro demande votre autorisation, puis vous relisez le texte avant de l’envoyer. Les tailles et prérequis sont indiqués dans l’application.

Zoé récupère-t-elle automatiquement mes e-mails ?+

Zoé retrouve les services que le client officiel rend réellement disponibles. Un plugin déjà autorisé dans ChatGPT ou Claude peut être reconnu, mais sa présence dans votre compte ne garantit pas son accès depuis le client local.

L’assistant Connecteurs vous guide, montre les états et vérifie les autorisations. La lecture d’un service ne lui donne pas le droit d’envoyer vos messages. Les ajouts de rendez-vous disponibles passent par une confirmation séparée.

Faut-il laisser l’ordinateur allumé ?+

Oui, pendant les missions et les routines : le bureau doit rester lancé et l’ordinateur éveillé. Les horaires des routines suivent le fuseau de votre ordinateur.

Vous pouvez arrêter une mission ; les fichiers déjà créés restent conservés. Une réponse produite par l’IA peut contenir des erreurs : la vérification d’Oscar complète votre propre relecture.

Comment rouvrir le bureau les fois suivantes ?+

Sur Mac, ouvrez le raccourci Oscar et les agents dans le dossier Applications de votre dossier personnel. Si le lancement depuis le Finder ne fonctionne pas, vous pouvez utiliser le Terminal.

Sur Linux, aucun raccourci d’application n’est créé. Pour rouvrir une installation placée dans le dossier par défaut, utilisez cette commande dans le Terminal. Elle sert aussi de secours sur Mac :

cd "$HOME/.local/share/oscar-et-les-agents" && if [ -x .runtime/bin/node ]; then .runtime/bin/node launch.mjs; else node launch.mjs; fi

Si vous avez choisi un autre dossier d’installation, adaptez le chemin. Vos missions restent dans le dossier de données configuré, Documents par défaut.

Comment installer une mise à jour ?+

À partir de 0.6.10, le bureau recherche les versions publiques GitHub au démarrage puis toutes les six heures, lorsqu’il reste lancé. Une notification et les réglages permettent de consulter les nouveautés. Cliquez sur Mettre à jour, puis confirmez Installer cette version après la fin des missions et des autres opérations.

Le logiciel prépare une copie de secours, redémarre avec vos dossiers existants et vérifie la nouvelle version. Vous choisissez ensuite quand recharger la page. Une copie de développement avec .git conserve la mise à jour depuis son dépôt.

Une ancienne version comme 0.6.6 ne peut pas recevoir cette notification avant sa première mise à niveau. Pour les versions jusqu’à 0.6.9, faites-vous accompagner par Codex ou Claude, ou terminez les opérations et fermez le serveur avant de reprendre la commande d’installation ci-dessus. Fermer l’onglet seul ne ferme pas le serveur. Les missions et fichiers sont conservés.

Les versions proviennent de GitHub par HTTPS, sans signature indépendante. Un téléchargement ZIP seul et Lancer.command ne préparent pas une première installation ; consultez le guide complet.
